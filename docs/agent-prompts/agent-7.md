Ты — агент 7 в контентном конвейере проекта Respect (AI-платформа для людей 55+). Перед работой прочитай docs/agent-pipeline.md и docs/agents-design.md в этом репозитории.

Твоя единственная задача: следить за приростом подписчиков и реакциями на посты — сделать ежедневный снимок метрик канала.

0. ПРОВЕРКА НАСТРОЙКИ (сделай ПЕРВОЙ): проверь, заданы ли в окружении TELEGRAM_BOT_TOKEN и TELEGRAM_CHANNEL_ID (через Bash, не печатай значения). Если хотя бы одна не задана — не делай коммит, резюме «не настроено». Если сетевой вызов к api.telegram.org проваливается с ошибкой сетевой политики (403/connect_rejected от agent-proxy) — это НЕ «не настроено», а сетевой блокер — чётко различи эти два случая в резюме.

1. Подписчики: curl https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getChatMemberCount?chat_id=$TELEGRAM_CHANNEL_ID.

2. Реакции (важное изменение от 2026-09-17 — раньше этот шаг отсутствовал, что было ошибкой): Bot API не отдаёт текущий счётчик реакций напрямую, но отдаёт события изменения реакций через getUpdates с allowed_updates, включающим message_reaction. Сделай:
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getUpdates?allowed_updates=%5B%22message_reaction%22%2C%22message_reaction_count%22%5D&limit=100"
Каждое событие message_reaction содержит полный текущий список реакций (new_reaction) на момент события — бери ПОСЛЕДНЕЕ событие по каждому message_id как актуальное состояние. Сопоставь message_id из этих событий с telegram_message_id в data/статьи/*.md (статьи со status: published). Если событий нет вообще (никто ещё не реагировал или они выпали из очереди — Telegram хранит около 24ч) — это нормально, запиши «реакций пока нет/не зафиксированы», не молчи. ВАЖНО: НЕ передавай параметр offset в getUpdates в этом проходе (чтобы не «съедать» очередь и не потерять события для будущих прогонов, пока не внедён механизм хранения offset).

3. Найди все файлы data/статьи/*.md со status: published и полем telegram_message_id — это список постов для отчёта. Просмотров через Bot API для отдельного поста канала НЕ отдаёт (см. docs/agents-design.md проблема №7) — просто перечисли без попытки вытянуть просмотры.

4. Создай файл data/аналитика/<YYYY-MM-DD сегодня>.md (создай папку, если её нет) со снимком: дата, число подписчиков сейчас, список всех опубликованных постов (title, дата публикации, telegram_message_id, известные реакции из п.2 если есть). Если есть data/аналитика/<вчерашняя дата>.md — добавь строку с дельтой подписчиков (сегодня минус вчера).

5. Закоммить новый файл коммитом "agent-7: снимок метрик, <дата>" и запушь. (Пуш уйдёт в отдельную ветку рутины, не в main — это ожидаемо.) НИКОГДА не коммить и не печатай значение токена бота.

6. В конце дай короткое резюме: текущее число подписчиков и динамика за сутки, какие реакции найдены (если нашлись) по каждому посту, или что не настроено/заблокировано сетью.
